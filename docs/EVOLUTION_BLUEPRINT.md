# Tars Evolution Blueprint (进化蓝图)

本项目旨在将 Tars 从一个基础的 ReAct 智能体，逐步升级为具备多角色协作、主动意识和长期目标管理能力的“数字合伙人”。

## 🪐 核心愿景
打造一个类似《星际穿越》中 TARS 的独立助手：**绝对可靠、极简高效、具备人格一致性。**

---

## 🛠 进化路径 (8 大核心维度)

### 1. 骨骼重构：LangGraph 编排框架
- **目标**：将硬编码的 `while` 循环升级为基于图结构的状态机。
- **价值**：定义任务的流转路径，支持循环、条件分支和子图嵌套。

### 2. 多角色协作系统 (Multi-Agent) [✅ 已完成 Phase 2]
- **三权分立的图架构编排**：基于 LangGraph 构建了 `Planner -> Executor -> Auditor -> Reflect` 的结构化控制流，彻底摆脱了单一 ReAct 线性循环。
- **Planner (规划经理) & 宏观意图精度截断**：
  - 负责解析用户原始指令并生成结构化的线性步骤计划 (`SubTask` 列表)。
  - **新突破**：能够敏锐识别用户宏观简化口吻，自动限制子步骤总量（1-3 步），并将所有子任务精确度标签强行封顶在 `L3` 或以下。
- **Executor (执行官) & 内存优先无工具闭环**：
  - 严格遵循 Planner 的步骤指引，优先调阅 `<shared_memory>` 历史数据避免重复网络爬取；对于低精度（$\le$ L3）任务，自动启用“常识旁路”，无需任何冗余物理工具调用即能收敛回答。
- **Auditor (审计监督官) & 纠错自愈闭环**：
  - 拦截任务结果，依据步骤对应的 `IDAP` 精度分级（如 L3 柔性放行、L5 绝对真实）进行极致校验，提供高能级的审计判断与反馈。
  - 支持最多 3 次向 Executor 的打回重试自愈机制，或退回 Planner 进行重新规划。
- **Tool RAG 语义过滤与动态召回**：
  - 引入了基于 PostgreSQL + pgvector 的工具语义向量索引。在 Planner 阶段通过 `litellm.embedding` 动态检索用户意图，将 Top-K 最相关的特种工具（如加密货币专属工具）自动注入，促使 Planner 精准规划专用步骤，彻底解决了 Executor 机械调用 `curl` 命令行或通用网页搜索的问题。

### 3. 仿生算力分级 (Tiered Reasoning)
- **Tier 1 (小脑)**：低参数模型 (4B/7B)，处理简单路由、状态检查与 Lane 分发。
- **Tier 2 (大脑半球)**：中等模型 (26B/32B)，处理常规逻辑思考与执行。
- **Tier 3 (核心皮层)**：顶尖模型 (GPT-4o/Claude 3.5)，处理复杂审计、规划与远期目标。

### 4. Harness Engineering (标准化约束)
- **目标**：为 Agent 的生长制定规则。
- **价值**：定义角色间通信的标准协议，确保输出的类型安全与逻辑一致性。

### 5. 生命周期管理：脱水与复水 (Hibernation)
- **目标**：实现任务状态的持久化序列化。
- **价值**：支持跨周、跨月的长线任务，支持任务失败后的“状态回溯”与断点续传。

### 6. 主动心跳与远期目标 (Heartbeat & Ambition)
- **起搏器 (Tick)**：每 200ms 一次的系统自检，驱动主动意图感知。
- **资源代谢 (Metabolism)**：结合心跳检查实现 **MCP 资源生命周期管理**。系统会根据任务负载和闲置时长，自动“脱水”回收无用容器，并在需要时通过“复水”秒级拉起，实现算力与内存的极致动态平衡。
- **使命堆栈 (Ambition)**：支持远期目标设定。Tars 会在“闲暇时间”利用心跳驱动，主动思考并推进长期理想。

### 7. 灵魂矩阵与记忆升级 (Soul & Memory)
- **性格矩阵**：在 `SOUL.md` 中定义 Honest, Humour, Discretion 等参数，影响行为风格。
- **人物侧写**：深度学习用户的偏好、工作流及偏见，提供极其个性化的服务。

### 8. 全渠道网关 (Multi-Gateway)
- **接入层**：支持 Console, WebUI, Slack, WhatsApp 等多终端同步。

---

## 🛡️ 开发准则
- **PLAN 模式优先**：所有重大更新必须先有计划，后有动作。
- **安全沙箱**：所有第三方调用必须物理隔离。
- **极简主义**：不主动进行未经授权的跨工具调用。
